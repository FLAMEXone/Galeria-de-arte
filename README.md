# Galería de Arte - A Través de Mis Ojos 🎨

Una galería de arte web interactiva que presenta obras maestras clásicas con una experiencia visual moderna y envolvente.

## 📖 Descripción

**A Través de Mis Ojos** es una galería de arte digital que transforma la manera en que se percibe y se siente el arte. Nos dedicamos a ofrecer una nueva forma de contemplar obras maestras, invitando a los visitantes a sumergirse en una experiencia más profunda, íntima y reveladora.

## ✨ Características

- **Navegación intuitiva** con Bootstrap 5
- **Galería interactiva** con modales informativos
- **Funcionalidad de ocultar/mostrar** obras de arte
- **Carrusel de imágenes** en la página principal
- **Formulario de contacto** con validación en tiempo real
- **Diseño responsivo** adaptable a diferentes dispositivos
- **Interfaz moderna** con iconos Font Awesome

## 🎨 Obras Presentadas

La galería incluye cinco obras maestras icónicas:

1. **El Jardín de las Delicias** - El Bosco (c. 1500)
2. **La Gran Ola de Kanagawa** - Hokusai (1831)
3. **Guernica** - Pablo Picasso (1937)
4. **La Noche Estrellada** - Vincent van Gogh (1889)
5. **El Entierro del Conde de Orgaz** - El Greco (1586)

## 🚀 Instalación y Uso

1. **Clona o descarga** el repositorio
2. **Abre** `Inicio.html` en tu navegador web
3. **Navega** entre las diferentes secciones usando el menú

No requiere instalación de dependencias adicionales, ya que utiliza CDNs para Bootstrap y Font Awesome.

## 🛠️ Tecnologías Utilizadas

- **HTML5** - Estructura del contenido
- **CSS3** - Estilos personalizados
- **JavaScript** - Interactividad y validaciones
- **Bootstrap 5.3.6** - Framework CSS responsivo
- **Font Awesome 6.5.0** - Iconografía

## 📄 Páginas del Sitio

### 🏠 Inicio (`Inicio.html`)
- Carrusel con obras destacadas
- Presentación de la galería
- Información sobre la misión y visión

### 🖼️ Galería (`Galeria.html`)
- Visualización de todas las obras
- Modales informativos para cada obra
- Funcionalidad de ocultar/mostrar imágenes

### 📞 Contacto (`Contacto.html`)
- Formulario con validación en tiempo real
- Campos: nombre, email, tipo de solicitud, mensaje
- Validaciones para nombre (solo letras, mín. 2 caracteres)
- Validación de email con formato correcto

### 📋 Presentación (`Presentacion.html`)
- Información académica del proyecto
- Datos de la asignatura y estudiantes

## ⚙️ Funcionalidades JavaScript

### Galería Interactiva
- Modales informativos con detalles de cada obra
- Botones para ocultar/mostrar imágenes
- Manejo de eventos y DOM

### Validación de Formulario
- Validación en tiempo real de campos
- Expresiones regulares para nombre y email
- Retroalimentación visual con colores
- Prevención de envío con errores

## 🎨 Diseño y Estética

- **Paleta de colores**: Tonos púrpuras y rosados suaves
- **Tipografía**: Fuentes web estándar con estilos personalizados
- **Layout**: Diseño centrado y responsivo
- **Componentes**: Cards, modales, carruseles y formularios estilizados
